# halftone-kit (copy-in)

Vendored from [ecgang/halftone-ui](https://github.com/ecgang/halftone-ui) via degit — not an npm dependency.

```
npx degit ecgang/halftone-ui/halftone-kit/core src/halftone/core
npx degit ecgang/halftone-ui/halftone-kit/react src/halftone/react
```

React adapters live in `react/`; the framework-free engine is in `core/`. App wrappers:
`src/components/halftone/SvbHalftoneProvider.tsx`, `HalftoneShowcase.tsx`.

Docs: https://halftone-ui.com/docs/
